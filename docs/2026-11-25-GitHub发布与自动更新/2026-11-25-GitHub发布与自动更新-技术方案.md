## 1. 背景与目标

AgentDot 目前只能通过本地脚本安装（`scripts/install.sh`），更新靠手动重新构建。用户要求：

- 通过 **GitHub Releases** 发布安装包，用户不跑命令行；
- 应用内部 **自动检查更新**；
- 用户点“升级”后，应用 **自动下载、校验、替换并重启**；
- 安装位置 `~/Applications`，避免管理员权限。

目标：用户从 GitHub Releases 下载 DMG → 双击打开 → 应用内一键安装到 `~/Applications` → 后续在应用内点“升级”完成自动更新。全程不需要终端命令。

## 2. 范围

### 2.1 In scope

- GitHub Releases 发布：DMG（首次安装）、ZIP（升级包）、`latest.json`（更新清单）、SHA256。
- GitHub Actions 自动构建/测试/打包/ad-hoc 签名/创建 Release。
- 应用内更新检查：启动时 + 每 24h + 菜单/设置手动检查。
- 用户点“升级”后自动下载 ZIP、Ed25519 + SHA256 校验、解压、校验 bundle id/version、调用 updater helper 替换并重启。
- 更新失败回滚；旧版本备份。
- 首次运行：应用自安装到 `~/Applications`、GUI 安装 hooks、可选开机自启。
- 更新 UI：面板横幅、菜单项、设置页版本/检查按钮、跳过版本。
- 文档、DMG README、密钥生成脚本、发布脚本、workflow。

### 2.2 Out of scope

- Apple Developer ID / notarization / Sparkle（当前无证书；以后可升级）。
- 静默后台更新（不询问用户）；每次升级由用户点击触发。
- 增量更新、灰度/beta 通道、回滚到任意历史版本。
- 自动更新 hooks 配置（helper 路径稳定，新 app 启动时自行刷新 helper）。
- App Store、Intel 通用二进制、公证。
- 工具自行 commit/push；GitHub 操作由用户通过 GitHub Desktop / Actions 完成。
- 多实例并发更新、系统级安装到 `/Applications`（若用户拖到 `/Applications`，更新需要管理员权限，本方案只保证 `~/Applications`）。

## 3. 方案对比与选择

| 方案 | 自动安装 | 前置条件 | 取舍 |
|---|---|---|---|
| Sparkle 2 | 是 | Apple Developer ID + notarization | 最成熟，但当前 0 签名身份，需 $99/年并配置证书/公证 |
| **自研 updater（本方案）** | 是 | 仅 GitHub + Ed25519 密钥 | 不依赖开发者账号；需自写下载/校验/替换/回滚 helper；首次安装仍有 Gatekeeper 提醒 |
| 自动检查 + 手动下载 | 否 | 无 | 最简单，但不满足“点升级自动安装” |

选择：**自研 updater**。使用 Ed25519 签名替代 Apple 代码签名作为更新身份；应用保持 ad-hoc 签名。

## 5. 总体架构

```
GitHub Actions (workflow_dispatch / tag v*)
  ├─ swift test + simulate
  ├─ build AgentDot / dot-hook / AgentDotUpdater
  ├─ inject version → ad-hoc sign .app
  ├─ DMG (first install) + ZIP (update)
  ├─ Ed25519 sign ZIP (secret key)
  └─ gh release create vX.Y.Z → assets: DMG, ZIP, latest.json, SHA256SUMS

App (in ~/Applications)
  ├─ UpdateService: GET latest.json (startup / 24h / manual)
  ├─ compare SemVer → banner "新版本 X"
  ├─ user clicks 升级:
  │    download ZIP → verify size/SHA256/Ed25519 → extract
  │    → validate AgentDot.app bundle id/version
  │    → copy AgentDotUpdater to temp → launch helper → terminate
  └─ AgentDotUpdater:
       wait old PID exit → backup old app → replace
       → xattr -dr quarantine → open new app → log
       → on failure restore backup
```

## 6. 更新清单 `latest.json`

```json
{
  "schema": 1,
  "version": "0.1.1",
  "minimum_macos": "13.0",
  "zip_url": "https://github.com/qiuzhaokun/agent-dot/releases/download/v0.1.1/AgentDot-0.1.1.zip",
  "dmg_url": "https://github.com/qiuzhaokun/agent-dot/releases/download/v0.1.1/AgentDot-0.1.1.dmg",
  "release_page": "https://github.com/qiuzhaokun/agent-dot/releases/tag/v0.1.1",
  "sha256": "hex...",
  "size": 12345678,
  "signature": "base64-ed25519-signature-over-zip-bytes",
  "published_at": "2026-11-25T08:00:00Z",
  "notes": "本次更新内容…"
}
```

- 签名对象：ZIP 文件原始字节。
- App 校验：`size`、`sha256`、Ed25519(`signature`, ZIP bytes, 内置公钥)。
- 解压后校验：`AgentDot.app/Contents/Info.plist` 的 `CFBundleIdentifier == dev.agentdot.app`，`CFBundleShortVersionString == manifest.version`。
- 不降级：`manifest.version > currentVersion`。
- URL 校验：host 必须 `github.com`，path 必须以 `/qiuzhaokun/agent-dot/releases/` 开头。
- 最大 ZIP：200MB；超过拒绝。

## 7. 应用内更新流程

### 7.1 检查

- 启动后异步检查一次；之后每 24h；菜单“检查更新…”和设置页“检查更新”手动触发。
- 自动检查失败静默；手动检查失败弹提示。
- 版本比较：语义版本（数字段比较）。
- 结果写入 `HUDViewModel.updateState`：
  - `idle` / `checking` / `available(UpdateInfo)` / `downloading(progress)` / `verifying` / `installing` / `failed(message)`。
- 同一版本被“稍后”后，自动检查不再弹横幅；手动检查仍显示；新版本号出现时重新显示。
- 开发环境（`swift run` / `--demo`，无 bundle 版本）跳过检查。

### 7.2 用户点“升级”

1. `UpdateService` 在后台 URLSession 下载 ZIP 到 `~/Library/Application Support/AgentDot/Updates/<version>/`，显示进度。
2. 校验 size/SHA256/Ed25519；失败 → 删除文件，`failed`，不安装。
3. `/usr/bin/ditto -x -k` 解压到同目录，校验 app bundle id/version。
4. 检查当前 app 父目录可写（`~/Applications` 应可写）；不可写 → 提示“请将 AgentDot 移到 ~/Applications”。
5. 复制 `Bundle.main/Contents/Helpers/AgentDotUpdater` 到 `Updates/<version>/AgentDotUpdater`，chmod 0755。
6. 启动 helper：
   ```
   AgentDotUpdater --wait-pid <app pid> --current-app <~/Applications/AgentDot.app>
                   --new-app <Updates/.../AgentDot.app> --expected-version <version>
   ```
7. 启动成功后 `NSApp.terminate(nil)`；启动失败 → `failed`，app 继续运行。

### 7.3 Helper 替换

`AgentDotUpdater`（独立 Swift executable，随 app 分发）：

1. 轮询 `kill(pid, 0)`，等待旧 app 退出，最多 60s；超时退出并写日志。
2. 校验新 app 的 `CFBundleIdentifier`/版本。
3. 备份旧 app 到 `~/Library/Application Support/AgentDot/Backups/AgentDot-<oldversion>-<timestamp>.app`，保留最近一份。
4. 将旧 app 移入备份，把新 app 移到原路径。
5. 失败则把备份移回原路径。
6. `xattr -dr com.apple.quarantine <new app>`（更新包由 URLSession 下载，通常无 quarantine；仍执行）。
7. `/usr/bin/open <new app>` 重启。
8. 写 `~/Library/Application Support/AgentDot/logs/updater.log`（不含用户内容）。
9. 清理 `Updates/<version>`（可选；失败保留供排查）。

### 7.4 状态与 hooks 兼容

- hooks 命令固定为 `~/.agent-dot/bin/dot-hook emit`；app 更新不改变该路径。
- 新 app 启动时 `HookInstaller.installHelperIfNeeded()` 原子刷新 helper。
- LaunchAgent 指向原 app 路径；替换后路径不变。
- `config.json`/`ui-state.json` 在 `~/Library/Application Support/AgentDot/`，不随 app 替换。
- 更新时正在运行的 Claude 会话不受影响；HUD 重启后重新读取会话状态。

## 8. 首次安装体验（不跑命令行）

1. 用户从 GitHub Releases 下载 `AgentDot-<version>.dmg`。
2. 打开 DMG，双击 `AgentDot.app`；ad-hoc 首次打开需右键 → 打开（或系统设置 → 仍要打开）。
3. 应用检测自身不在 `~/Applications`：显示安装横幅“安装到 ~/Applications（自动更新需要）” → 点击后复制自身、去 quarantine、重启新副本。
4. 新副本启动，面板提示“Hooks 未安装，点此修复” → 点击合并 `~/.claude/settings.json`（备份、保留 cc-status）。
5. 设置里可开“开机自启”。
6. DMG 内含 `README.txt`，写明以上步骤和 Gatekeeper 说明。

> 如果用户把 app 放在 `/Applications`：应用可用，但自动更新在父目录不可写时会提示“请移到 ~/Applications”；不保证 `/Applications` 自动替换。

## 9. GitHub Actions 发布

### 9.1 workflow

`.github/workflows/release.yml`：

- 触发：
  - `workflow_dispatch`：输入 `version`（如 `0.1.1`）、`notes`（可选）、`prerelease`（默认 false）。
  - `push` tags `v*`。
- `permissions: contents: write`。
- `runs-on: macos-latest`。
- 步骤：
  1. checkout。
  2. 解析版本（input 或 tag 去掉 `v`），校验 `^[0-9]+\.[0-9]+\.[0-9]+$`。
  3. `bash scripts/test.sh`、`bash scripts/simulate.sh`。
  4. `AGENTDOT_VERSION=$VERSION AGENTDOT_UPDATE_PRIVATE_KEY=${{ secrets.AGENTDOT_UPDATE_PRIVATE_KEY }} bash scripts/package-release.sh`。
  5. `gh release create "v$VERSION" dist/*.dmg dist/*.zip dist/latest.json dist/SHA256SUMS --title "AgentDot $VERSION" --notes "$NOTES"`（runner 自带 `gh`，用 `GH_TOKEN: ${{ github.token }}`）。
- 不需要 Apple 证书；不需要第三方 Action。

### 9.2 打包脚本

`scripts/package-release.sh <version>`：

1. `swift build -c release --product AgentDot`、`dot-hook`、`AgentDotUpdater`。
2. 组装 `AgentDot.app`（含 `Contents/Helpers/{dot-hook,AgentDotUpdater}`）。
3. 用 `PlistBuddy` 注入 `CFBundleShortVersionString`、`CFBundleVersion`。
4. `codesign --force --deep --sign -` + `codesign --verify --deep --strict`。
5. ZIP：`ditto -c -k --sequesterRsrc --keepParent AgentDot.app AgentDot-<version>.zip`。
6. DMG：staging（app + `README.txt`）→ `hdiutil create -volname AgentDot -srcfolder ... -ov -format UDZO AgentDot-<version>.dmg`。
7. `shasum -a 256` → `SHA256SUMS`。
8. 用私钥对 ZIP 签名（`scripts/sign-update.swift`），生成 `latest.json`（含 zip/dmg URL、sha256、size、signature、release page、notes）。
9. 输出 `dist/`。

### 9.3 密钥生成

- `scripts/generate-update-key.swift`：用 CryptoKit 生成 Ed25519 密钥对。
- 公钥（base64）写入 `Resources/Info.plist` 的 `AgentDotUpdatePublicKey`。
- 私钥（base64）写入本地 0600 文件（gitignore），用户复制到 GitHub repo → Settings → Secrets and variables → Actions → `AGENTDOT_UPDATE_PRIVATE_KEY`。
- 私钥绝不出现在日志/仓库/聊天中；丢失后需换公钥发新版（旧版无法自动更新）。

## 12. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| 无 Apple Developer/notarization | 首次安装 Gatekeeper 拦截；用户信任度低 | 明确 README；以后升级 Developer ID + Sparkle |
| 私钥泄露 | 攻击者可签发恶意更新 | 仅存 GitHub secret；仓库 2FA；泄露即换公钥发新版 |
| 替换正在运行的 app | 文件占用/半更新 | helper 等待 PID 退出；备份/回滚 |
| `/Applications` 不可写 | 自动更新失败 | 强制/引导 `~/Applications`；可写检查 |
| 更新包损坏/网络中断 | 安装失败 | size/SHA/Ed25519 校验；失败不安装；保留旧版 |
| GitHub Release 被篡改 | 下载恶意包 | Ed25519 + SHA；公钥内置；URL host/path 校验 |
| 多实例运行 | 替换冲突 | 单实例假设；helper 等待目标 PID；后续可加单实例锁 |
| 首次从 DMG 移动 | 路径/quarantine | 自安装复制、去 quarantine、重启；README |
| `latest.json` 未上传/404 | 不提示更新 | 自动检查静默；手动检查提示“检查失败” |
| GitHub Actions 版本与本地不一致 | 版本号错误 | workflow 校验 semver；Info.plist 注入；设置页显示 bundle 版本 |

## 14. 实施修订（review 后）

- **D19 收紧**：严格只允许 `~/Applications` 自动更新；`/Applications` 会提示移动到 `~/Applications`，不尝试原地替换。
- **D21 调整**：改为 **app 自替换优先**（`UpdaterEngine` 在 app 进程内备份 → 替换 → 回滚），避免 macOS App Management 对裸 helper 替换 app bundle 的拦截；`AgentDotUpdater` 保留为备用/手动工具。
